# ADR-0001: Authentication architecture

## Status

Accepted

## Context

The login service needs a lockout policy that is testable and central.

## Decision

Encapsulate all lockout policy constants in a single `SecurityPolicy` class.
`AuthService` owns the per-account attempt counter; lockout enforcement must
live in `AuthService.login`.

## Consequences

- Positive: policy changes are one-file edits.
- Negative: `AuthService` grows lockout state management.
